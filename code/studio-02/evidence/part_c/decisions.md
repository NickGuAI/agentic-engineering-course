# Decisions

- 2026-09-17: Decided to use Markdown (.md) files for storage because it is human-readable, widely supported, and easy to parse with CLI tools.
- 2026-09-17: Decided to name the command `memo` because it is short, memorable, and clearly describes the purpose of the tool.
- 2026-09-17: Decided to use ISO 8601 (YYYY-MM-DD) as the date format because it is a standard, sortable, and unambiguous format for filenames and metadata.
- 2026-09-17: Decided to implement the Fibonacci sequence iteratively starting with 0 and 1 for the `fib.py` script, as it is more efficient than a naive recursive implementation.
