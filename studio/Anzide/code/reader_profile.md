# Reader profile

Edit this file as your knowledge changes. The writer agent reads it on every run.

## Who the reader is
A bright student with a bachelor's degree in Software Engineering, taking COMS W4995 Agentic Engineering.

## Already knows (never explain)
- Programming in Python; data structures; algorithms; testing; debugging.
- Git and GitHub basics (clone, branch, commit, push, pull request).
- What an API, JSON, an HTTP request, and a library/package are.
- Running a command in a terminal and reading its output.
- What an LLM is and how to chat with one.

## Weak spots (explain briefly the first time they matter)
- **Systems engineering:** operating-system concepts (processes, environment variables, PATH, file permissions, stdin/stdout, exit codes), shells and shell scripts, package managers and global vs. local installs, networking (ports, localhost, TLS), containers and sandboxes, sessions and statelessness, concurrency, logs and monitoring.
- **Hardware (knows very little):** CPU vs. GPU, RAM vs. disk vs. VRAM, why model size and context length cost memory and time, bandwidth and download sizes, what "runs on a laptop" implies.
- **Agent/LLM internals that lean on the above:** tokens, context window, latency, cost per token, caching.

## How the reader likes to learn
- Step by step, doing things, with a way to confirm each step worked.
- Short sentences. No filler, no motivation speeches, no repeated summaries.
- An analogy to a software-engineering idea they already know beats a formal definition.
