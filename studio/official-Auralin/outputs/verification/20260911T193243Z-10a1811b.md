## [Scaling Managed Agents: Decoupling the brain from the hands](https://www.anthropic.com/engineering/managed-agents)

2026-04-08 · anthropic-engineering · Engineering · new

Anthropic describes Managed Agents as a hosted service separating durable session logs, agent harnesses, and execution sandboxes behind replaceable interfaces. This architecture supports independent recovery, retrieval of earlier events outside the active context window, and credentials kept outside the sandbox. Anthropic reports that provisioning containers only when needed reduced median time to first token by roughly 60% and the 95th percentile by over 90%.

**Why it matters (analysis):** Separating persistent records from disposable execution components can improve recovery and constrain credential exposure. Stable interfaces also let developers revise context management and orchestration as models change.

> Each became an interface that made few assumptions about the others, and each could fail or be replaced independently.

## [How we built Claude Code auto mode: a safer way to skip permissions](https://www.anthropic.com/engineering/claude-code-auto-mode)

2026-03-25 · anthropic-engineering · Engineering · new

Anthropic describes Claude Code auto mode as automated approval using a prompt-injection probe and a two-stage action classifier. The classifier evaluates user messages and tool calls while excluding assistant prose and tool results, with additional checks at subagent handoffs. Anthropic reports a 0.4% false-positive rate on benign traffic and a 17% false-negative rate on 52 real overeager actions, presenting the feature as an improvement over skipping permissions rather than a replacement for careful review of high-stakes actions.

**Why it matters (analysis):** Approval automation trades reduced interruption against missed unauthorized actions. The design illustrates why authorization checks, injection defenses, and subagent boundaries need separate treatment and evaluation.

> The classifier sees only user messages and the agent&#x27;s tool calls
