At 8:00 AM EST. Run this pass. Use this delegation card and the above directory's directory guideline in the readme for evidence on how to structure this folder. 


## Context
What relevant inputs, files, tools, target audience, or learning preferences should the AI consider?
You should consider me as the primary audience. An undergraduate student interested in AI and trying to stay up to date with the latest news. Personalize it. 

You should use available search tools, and organize findings. 

Check: 
Anthropic News
Anthropic Engineering
OpenAI News
X.com

Return a concise Markdown briefing with no more than 5 stories. 
They should include:
- headline
- source name
- publication / posting date
- one sentence summary
- short description
- link to source

## Success criteria
A successful run means I wake up at 8:01 AM and see a fully ready briefing of the latest news. 
If something happened like an important or cool paper, I should know about it. Highlight interesting papers, not just official statements/reports. 


## Restrictions
Do not look at spammy articles or posts trying to sell or promote material. Don't set this up on my mac. But only run the agent when the process is running. i.e. run, wait 24H, run, wait 24H etc.
