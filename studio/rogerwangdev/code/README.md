# AI News Digest Code

Run this from the repository root:

```bash
python studio/rogerwangdev/code/ai_news_digest.py
```

The script fetches:

- https://www.anthropic.com/news
- https://www.anthropic.com/engineering
- https://openai.com/news/

It writes:

- `studio/rogerwangdev/outputs/weekly-ai-news-digest.md`
- `studio/rogerwangdev/outputs/weekly-ai-news-trace.jsonl`

The script performs a manual run only. It does not enable the Monday 7:00 AM Eastern Time automation by itself.
