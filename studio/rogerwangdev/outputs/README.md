# Outputs

This folder contains Studio 01 artifacts for the AI news digest option.

- `prompt-ai-news-digest.md`: prompt used for the delegated weekly AI news job.
- `ai-news-digest.md`: digest plan and relevance criteria.
- `weekly-ai-news-digest.md`: generated digest from the manual run.
- `weekly-ai-news-trace.jsonl`: source-check trace from the manual run.
- `run-record.md`: run record and changed-condition comparison.

The personal explanation file belongs at `studio/rogerwangdev/explanation-rogerwangdev.md` and should be written by the student in their own words.
