1. What is AI?

The useful question is not merely whether a machine looks intelligent, but what criterion we use to judge it. The lecture contrasts four criteria along two axes: thought versus behavior, and resemblance to humans versus rational correctness. pp. 8–19

Thinking humanlyModel how people actually reason; this requires empirical theories of cognition and a choice of abstraction (knowledge or neural circuits). pp. 13–14
Thinking rationallyFormalize valid reasoning with logic. It is limited by what can be represented and by computational explosion. pp. 13, 17
Acting humanlyJudge behavior by its resemblance to a person's. In the Turing test, a human interrogator cannot reliably distinguish the machine in conversation. pp. 15–16
Acting rationally ★Choose actions expected to achieve the goal, given available information. This is the course's main perspective. pp. 18–19
Recall the distinction: passing a human-imitation test is not the same as choosing the best action. A rational agent need not think like a human or even be human-like.

The deck opens with course logistics: prerequisites include data structures, basic probability and linear algebra, and Python or a similar language; it describes five coding and four conceptual assignments. Consult the live course site for operational dates and policies, which may change. pp. 2–6

2. The unifying idea: a rational agent

An agent perceives an environment and acts on it to accomplish a task. The slide defines the agent abstractly as a mapping from percepts to actions and distinguishes the physical/computing architecture from the program running on it. p. 51

Environment→ percepts →Agent = architecture + program→ actions →Environment

Rationality means selecting the action with the best expected outcome according to a performance measure, using the information available. It does not mean omniscience: uncertainty and computational limits constrain what the agent can know or calculate. The course aims to design programs that perform as well as possible within those limits. pp. 18, 51

Example: a route-finding agent sees its starting city and a destination, considers possible road actions and path costs, and chooses a route toward the destination. A game-playing agent must instead prepare for an opponent's possible responses. These are different decision structures, not simply different application areas. pp. 52–55

3. Classical ways to choose actions

Search versus adversarial search pp. 52–55

Search explores future states and action sequences, with paths of different depth and cost. Uninformed search (BFS, DFS, UCS) uses no domain-specific estimate of distance to the goal; informed search (greedy search, A*) uses a heuristic to guide exploration. The route map on p. 53 illustrates a start at Las Vegas and a goal at Calgary; the lecture does not calculate a particular optimal route.

In an adversarial game, an opponent controls some moves. The solution is a contingent strategy/policy—“if they do this, respond that way”—rather than one fixed path. The deck previews minimax, alpha–beta pruning, and stochastic games.

Constraints and uncertainty pp. 56–58

A constraint satisfaction problem (CSP) specifies variables, their possible assignments, and conditions that must all hold. For Sudoku, let Xr,c be the digit in row r, column c, where r,c range from 1 to 9. Assign each cell a digit 1–9 so every row, column, and 3×3 box contains all nine digits. The two slides show an incomplete grid and a filled solution.

A Bayesian network represents uncertain dependencies: nodes are random variables; directed edges indicate direct probabilistic influence. Conditional independence allows a compact factorization of the joint distribution:

P(X1, …, Xn) = ∏i=1n P(Xi | Parents(Xi))

Here Xi is variable i, n is the number of variables, and Parents(Xi) are its parent nodes. The formula says to multiply each variable's conditional distribution given its parents. The lecture names conditional independence, d-separation, inference, and belief propagation without deriving them. p. 58

4. Learning from examples

Machine learning asks how a program can improve with experience. The contrast to keep straight is whether examples carry target labels. pp. 59–62

Unsupervised clusteringInput: unlabeled points x1, …, xm ∈ X ⊆ ℝd. Learn an assignment f: X → {C1, …, Ck} to k clusters. The figure groups nearby points without a supplied class answer. p. 60
Supervised binary classificationInput: labeled pairs (xj, yj), with yj ∈ {−1,+1}. Learn h: X → {−1,+1} for new points; the figure shows a boundary separating two classes. Spam versus ham is an example. p. 61

In this notation, m is the number of examples, d is the number of input features, and k is the number of clusters. Ensembles combine multiple predictors: random forests vote across trees trained on randomized data/features, whereas gradient boosting builds trees sequentially to correct earlier errors. p. 62

Deep learning learns successive feature representations rather than relying only on hand-engineered features. The network diagram has input, hidden, and output layers; for images, a CNN slides shared filters across local regions, pools representations, and can progress from edges to shapes to objects. The lecture surveys the historical progression from neural networks and backpropagation to CNNs, transformers, and foundation models. pp. 63–65

5. From attention to agentic systems

Attention lets a token relate directly to other tokens, even at long distance. The deck contrasts this with sequential RNN processing and shows an encoder–decoder transformer diagram. Transformer layers combine self-attention and feed-forward processing; multiple heads learn different relationships, and positional information supplies order that attention alone lacks. Parallel sequence processing helps scaling. This is an architectural overview, not a derivation of attention weights. pp. 66–68

Broad pretraining→Foundation model→Prompt / fine-tune→Downstream task

A foundation model is pretrained broadly and adapted to many tasks by prompting or fine-tuning. Multimodal systems connect text, image, audio, or video representations; the slides use image–caption alignment as an example. pp. 69–70

Retrieval-augmented generation (RAG) searches an external collection for relevant material and supplies the retrieved passages as context for generation. It can ground an answer in information absent or stale in training data; retrieval does not itself guarantee truth. p. 71

Question→Retrieve documents→LLM + context→Answer

Reinforcement learning (RL) learns decisions through interaction and delayed reward, aiming to maximize long-run reward in an uncertain environment. In the agent–environment diagram, an action at goes to the environment and the next state st+1 and reward rt return. RLHF uses human preferences over responses to learn a reward signal for tuning language models. pp. 72–73

Agentic AI extends one-shot responses into multi-step goal pursuit with tools, memory, planning, and feedback. The slide's “LLM as operating system” picture places tools, files, browsers, other models, and input/output around the LLM. Treat “agent = LLM + tools, memory, and planning” as this lecture's conceptual shorthand, not a formal equation. pp. 74–75

6. Where the field came from—and where it is used

The application gallery spans speech and conversation, handwriting, translation, robotics, recommendation, search, email, vision, medical imaging, games, autonomous driving, generative assistants, protein structure prediction, and mathematical reasoning. The examples illustrate different underlying methods: Deep Blue emphasizes search; Watson language understanding and extraction; AlphaGo learning plus search; AlphaFold deep learning for structure prediction. These are illustrations, not proofs that one technique solves all AI problems. pp. 20–42

AI draws on philosophy and logic, mathematics and probability, economics and decision theory, neuroscience and psychology, computer engineering, control theory, and linguistics. The historical sketch moves from early logic and Turing, through Dartmouth and symbolic programs, expert systems and an “AI winter,” to probabilistic and data-driven methods, powerful hardware, and LLMs. pp. 43–49

7. Responsible AI is a design constraint throughout

Accuracy is only one goal. Models may reproduce bias; decisions may be hard to interpret; systems can fail outside a lab or act against human intent; and data can be exposed. The final slides ask for inclusive systems that balance accuracy, safety, privacy, nondiscrimination, and transparency. The closing spectrum groups the course into classical AI (states, variables, logic), machine learning (ensembles, neural networks, attention), and modern systems (foundation models, grounding, agency), with ethics across all three—not an afterthought. pp. 76–78

Self-check

1. Why can a rational agent fail the Turing test and still be successful?

Its target is the best expected outcome under its performance measure, not human-like conversation. The tests use different criteria. pp. 16, 18

2. Why is a game solution a policy rather than a fixed route?

The opponent controls moves; the agent must choose a response conditional on what the opponent does. p. 55

3. In the Bayesian-network formula, what permits the product of local conditional terms?

The network's conditional-independence structure: each variable is conditioned on its parent variables. p. 58

4. What is supplied in classification that is absent in clustering?

Class labels for the training examples; clustering receives unlabeled examples and seeks groups. pp. 60–61

5. What roles do positional encoding and retrieval play in different systems?

Positional encoding gives a transformer information about token order; retrieval supplies external documents as context for an answer. pp. 68, 71

6. How does agentic AI connect back to the lecture's opening definition?

Both center an agent that perceives, acts, and pursues a goal; LLM-based agents add tools, memory, and multi-step planning. pp. 51, 74–75
