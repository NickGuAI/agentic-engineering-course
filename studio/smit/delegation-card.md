# Delegation Card

## Task
Produce a weekly AI research update as a Markdown file summarizing the most important recent developments from Anthropic News, Anthropic Engineering, and OpenAI News.

## Context
Use only the approved sources listed in Studio01. Focus on developments from the most recent 7 days. The output is for a technical student audience and should be concise, easy to inspect, and useful for quickly understanding what changed and why it matters.

## Success criteria
A successful run creates a Markdown report that:
- includes 3–5 relevant recent updates,
- gives the title, source, date, short summary, and why it matters for each item,
- contains valid source links,
- avoids duplicate stories,
- does not invent information if there are too few qualifying updates.

## Restrictions
Do not use sources outside Anthropic News, Anthropic Engineering, and OpenAI News. Do not fabricate missing details or citations. Do not include API keys or private information in files or logs. If a page cannot be accessed or verified, skip it and report the limitation instead of guessing.
