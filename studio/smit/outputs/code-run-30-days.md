### Claude discovers a novel enzyme system with CRISPR-like repeats

- **Source/date:** Anthropic News — 2026-09-23
- **Summary:** Anthropic's life sciences research group used Claude agents to search reverse transcriptases in DNA sequence data and identify a previously uncharacterized enzyme system (ART) with CRISPR-like repeat patterns, found mainly in bacteriophages.
