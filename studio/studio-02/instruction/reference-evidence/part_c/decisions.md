# Decisions

- 2026-09-17 — Storage format: Store notes as one plain-text file per note because it is human-readable and requires no parsing library.
- 2026-09-17 — Command name: Name the tool `note` because it is short, clear, and directly describes its purpose.
- 2026-09-17 — Note date format: Record each note date in ISO 8601 `YYYY-MM-DD` format because it is unambiguous and sorts chronologically.
- 2026-09-17 — Fibonacci implementation: Start the sequence at 0 and generate it iteratively, printing each of the first 20 numbers on its own line because this is the conventional sequence definition and avoids recursive overhead.
