# Project Decisions and Instructions

- Check if a file named `decisions.md` exists in this directory before starting any task.
- If `decisions.md` exists, read it completely before doing anything else.
- When you make a decision worth remembering for later, document it immediately.
- Append a new dated entry to `decisions.md` describing the decision and the rationale behind it.
- Never delete or rewrite any earlier entries in `decisions.md`; only ever append new ones.
- If `decisions.md` does not exist yet, create it when you make your first decision.
