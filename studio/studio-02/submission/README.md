# Submission

* Copy `_template/` to a new folder named after your team (e.g., `submission/<team>/`).
* Never edit the files inside `_template/` itself—copy it, then edit your copy.
* When you run the Part A/B/C scripts with `--team <name>`, they write their evidence files directly into `submission/<name>/evidence/` for you—you don't create that path by hand.
* Fill in `EXPLANATION.md` inside your team's folder.
