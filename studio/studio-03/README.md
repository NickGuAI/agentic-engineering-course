# Studio 03: ReAct and Plan-and-Execute

```text
Same research question ──┬──→ ReAct: question → your loop ─────────┐
                         └──→ Plan: tools-off plan → same loop ─────┤
                                                                    ↓
                                              reports + comparable traces
```

In this laptop assignment, your team will build a minimal OpenAI Responses loop and save a direct/ReAct run, then compare it with a plan-first run on the same research question. Start with [the instructions](instruction/Studio_Instruction.md). Course code and the fixed question are in [instruction/code](instruction/code/README.md); copy the [submission template](submission/_template/EXPLANATION.md) into your team folder.

Work in your team’s private course repository using macOS, Linux, or Windows with WSL and Bash. Studio 03 does not use a hosted in-lecture sandbox.
