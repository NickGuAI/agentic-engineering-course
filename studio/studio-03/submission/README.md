# Studio 03 Submission

Copy `_template/EXPLANATION.md` into your team’s folder, then edit your copy. Do not edit the template in place.

```text
submission/<team>/
├── agent.py
├── EXPLANATION.md
└── evidence/
    ├── react/<run-id>/
    └── plan/<run-id>/
```

Run both modes with `--team <team>` so the evidence is written to your folder. Use the Part A direct/ReAct run as the Part B baseline when its question and settings match. Each run contains structured course evidence such as `trace.jsonl`, `report.md`, `plan.md`, and `summary.json`. Keep both runs, including failures, and refer to their run IDs in your explanation. The course-generated, redacted traces are required for this assignment. Do not commit API keys or raw provider/session logs.

Push your team’s completed work to its private course repository and follow the existing CourseWorks submission instructions.
