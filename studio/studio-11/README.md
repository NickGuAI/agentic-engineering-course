# Studio 11: Evaluate Your AI Coding Workflow

```text
  your AI coding tools        tasks.csv               claims.csv, failures.md       retest/
 +--------------------+     +-----------------+     +-----------------------+     +-------------------+
 | 10+ real tasks,    | --> | time with AI,   | --> | claimed vs verified;  | --> | 3 failed tasks,   |
 | each with its full |     | reviewing and   |     | where each failure    |     | before and after  |
 | session log        |     | fixing per task |     | began                 |     | one change        |
 +--------------------+     +-----------------+     +-----------------------+     +-------------------+
```

Evaluate the AI coding workflow your team already uses on its project, from the session logs your coding agents write. Read each task's time with AI, time reviewing and time fixing from its trace. Check what the agent said it did against the records. Find where each failure started, then change one thing and run three failed tasks again. The tools, the tasks and the change are yours. You are graded on four checkpoints and your explanation, 10 points in all.
